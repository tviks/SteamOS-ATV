# Android TV 16 на Steam Deck

Переносимый комплект для установки Android TV 16 через Waydroid на SteamOS, запуска из игрового режима и управления стиками Deck либо пультом Google TV на телефоне.

Образы: [WayDroid-ATV, релиз 20260403](https://github.com/WayDroid-ATV/waydroid-androidtv-builds/releases/tag/20260403), LineageOS 23.0, x86_64, **GAPPS**. Комплект не содержит и не зеркалирует образы: они скачиваются с SourceForge автора. SHA-256 зафиксированы в установщике и соответствуют [системному OTA-манифесту](https://waydroid-atv.github.io/ota/a16-tv/system/lineage/waydroid_x86_64/GAPPS.json) и [манифесту vendor](https://waydroid-atv.github.io/ota/a16-tv/vendor/waydroid_x86_64/MAINLINE.json).

## Что потребуется

- Steam Deck с SteamOS и обычной учётной записью `deck`, UID 1000, домашним каталогом `/home/deck`. Это не универсальный установщик для других Linux.
- Совместимый [SteamOS Waydroid Bundle](https://github.com/pjohno/steamos-waydroid-bundle), Waydroid не ниже 1.6.3. При отсутствии совместимого bundle установка останавливается: не подменяйте его сборкой для другой версии SteamOS.
- Desktop Mode, Konsole, интернет и пароль `sudo`. Если пароль ещё не задан, выполните `passwd` и задайте собственный пароль.
- Рекомендуется не менее **20 ГиБ свободного места** в `/home`. Подготовка основы создаёт отдельный обычный Android, затем этот комплект создаёт TV; только для этапа TV проверяется минимум 8 ГиБ. Образы и данные не помещаются в маленький системный `/var`.
- Для Google TV — телефон и Deck в одной домашней Wi-Fi сети без изоляции клиентов. Текущая реализация использует Wi-Fi-интерфейс `wlan0` и IPv4, не Ethernet/VPN.

Проверенная рабочая конфигурация: SteamOS 3.8.28, ядро 6.18.50-valve2, Waydroid 1.6.3, Android TV 20260403. На этой системе подтверждены запуск через Steam, стики/крестовина/A/B и Google TV на Xiaomi, включая перемещение ровно на один пункт. **Новый полный проход установщика на очищенном Deck не выполнялся**; проверки комплекта описаны в [docs/TESTING.md](docs/TESTING.md).

## Установка на чистую SteamOS

1. Перейдите в Desktop Mode: кнопка Steam → питание → «Перейти на рабочий стол».
2. Распакуйте весь комплект, например в `/home/deck/android-tv16-steamdeck`. Не копируйте только один файл: установщику нужны каталоги `scripts` и `runtime`.
3. Откройте Konsole и выполните:

```bash
cd ~/android-tv16-steamdeck
bash install.sh --bootstrap
```

Команда сначала запускает официальный для этого комплекта установщик основы `pjohno/steamos-waydroid-bundle`. Новый checkout фиксируется на проверенной ревизии `8f5cc2a4f55010dc480f153350a7547b501fd49f`; уже существующий checkout не сбрасывается и не обновляется автоматически.

В окнах установки основы:

- Введите свой пароль `sudo`, подтвердите установку подходящего bundle и пакетов.
- На чистой системе выберите обычный **Android 13 с Google Play**. Это отдельная базовая среда; TV 16 будет установлен следующим этапом в другой каталог. Не нужно запускать или настраивать этот Android.
- В конце **откажитесь от перехода в Gaming Mode**, чтобы продолжился этап TV 16. Если уже перешли — вернитесь в Desktop Mode и выполните `bash install.sh` без `--bootstrap`.

Этап TV скачивает примерно 1,2 ГБ с SourceForge, проверяет контрольные суммы, распаковывает образы и ставит исправления. Если потребуется пакет `socat`, появится подтверждение Pacman. Установщик не отключает проверку зависимостей и восстанавливает read-only режим SteamOS, если временно отключал его для этого пакета.

4. Добавьте ярлык в Steam **один раз**:

```bash
bash add-to-steam.sh
```

Steam должен быть открыт. Если добавление не сработало, используйте «Игры → Добавить стороннюю игру» и выберите `Android TV 16`. Можно указать `/home/deck/Android-TV-16-Steam.sh` вручную. Совместимость Proton не включайте. Повторное добавление может создать дубль.

5. Вернитесь в Gaming Mode → библиотека → «Сторонние» → **Android TV 16** → «Играть».
6. Дождитесь первого запуска, выберите язык и завершите настройку Android. На экране обязательного Bluetooth-пульта останавливаться не нужно: этот шаг отключён свойством сборки.

Скрипт установки запускайте **без `sudo`**: он сам запросит нужные права. Не запускайте установку основы по SSH — её окна рассчитаны на локальный Desktop Mode.

## Если Waydroid уже установлен

Закройте любой Android. Убедитесь, что установлен именно совместимый SteamOS Waydroid Bundle, затем:

```bash
cd ~/android-tv16-steamdeck
bash install.sh
bash add-to-steam.sh   # только если ярлыка TV 16 ещё нет
```

Существующие основной и тестовый Android не заменяются. Они могут оставаться установленными, но запускать их одновременно с TV нельзя: у них общий контейнер Waydroid и точка `/var/lib/waydroid`.

Для обновления **только наших скриптов/правил**, без скачивания или замены образов:

```bash
bash install.sh --repair
```

Закройте TV перед восстановлением. Приложения, входы в аккаунты и сопряжение телефона сохраняются. Установщик откажется применять исправления к другой версии образов или неоднозначному незавершённому состоянию вместо его автоматического удаления. Предыдущие системные файлы комплекта сохраняются в `/etc/waydroid-atv16/backups/`.

## Управление на Deck

В Steam для Android TV 16 выберите шаблон контроллера **«Геймпад с джойстиками»**. Левый стик/крестовина — перемещение, A — выбор, B — возврат. Не выбирайте шаблон, который заменяет все кнопки клавиатурой.

Исправление Android 16 автоматически передаёт виртуальный Steam Input геймпад в контейнер и отслеживает его переподключение. Физический контроллер Deck и прочие устройства ввода не перенастраиваются.

## Пульт Google TV с телефона

1. Запустите Android TV через Steam и оставьте его открытым.
2. Подключите телефон к той же домашней Wi-Fi сети.
3. В Google TV откройте «Пульт» / «Телевизоры рядом».
4. Выберите **Steam Deck Android TV**.
5. Введите код, показанный Android TV на Deck, и подтвердите сопряжение.
6. Проверьте короткое нажатие вправо, ОК и «Назад». Сопряжение сохраняется; код не нужен при каждом запуске.

Пульт доступен только пока TV запущен. Если сменили Wi-Fi или Deck получил другой IP, закройте TV через Steam и запустите заново. Не настраивайте проброс этих портов в интернет на роутере.

На Deck автоматически создаются LAN-прокси TCP 6466/6467 и отдельное объявление mDNS. Они слушают Wi-Fi IPv4 Deck; TCP-клиенты допускаются только из подсети этого интерфейса. Временные правила firewall убираются при нормальном выходе. ADB в домашнюю сеть не публикуется, настройки Avahi не заменяются.

В Android создаётся `/dev/uinput`, а устройство `virtual-remote` передаётся системе ввода. Правило udev исключает **только этот Google-пульт** из обработки Steam/gamescope: иначе одно нажатие приходило по нескольким путям и перескакивало приложения. Стики продолжают работать независимо.

## Запуск, выход и диагностика

Обычный запуск — ярлык Steam. Для запуска из Desktop Mode:

```bash
bash start.sh
```

Для выхода используйте Steam → «Выйти из игры». Нормальное завершение останавливает контейнер и вспомогательные службы, снимает TV bind mount и восстанавливает прежний `kernel.pid_max`.

Диагностика без переустановки и сброса:

```bash
cd ~/android-tv16-steamdeck
bash doctor.sh
tail -n 100 ~/Android_Waydroid_ATV16/steam-launch.log
```

Во время работы TV подробный журнал Android можно посмотреть так:

```bash
sudo env XDG_DATA_HOME=/home/deck/.local/share/waydroid-atv16 \
  waydroid shell -- logcat -d -t 300
```

Не публикуйте полный журнал без проверки: там могут быть адреса сети и сведения об аккаунтах.

## Частые проблемы

**Нет совместимого bundle / после обновления SteamOS не запускается.** В Desktop Mode запустите установщик основы снова. При наличии основной Android-среды его обычный запуск выбирает восстановление. Затем выполните `bash install.sh --repair`. Если совместимого bundle ещё нет, дождитесь его; не обходите проверку ABI.

**Другой Android активен / точка уже смонтирована.** Полностью закройте текущий Android; если состояние осталось зависшим, перезагрузите Deck. Установщик не будет принудительно занимать его точку монтирования.

**Ярлык сразу закрывается, в журнале нет новой попытки.** В прежнем launcher `steam-launch.log` мог стать root-owned, и повторный запуск не мог открыть его. Текущий комплект использует отдельный `tee`-процесс: в контейнер передаётся pipe, а не файловый дескриптор журнала. Старый недоступный журнал автоматически переносится в `steam-launch.previous.log`, новый создаётся от `deck`. Обновите скрипты командой `bash install.sh --repair` при закрытом TV.

**Пульт не виден.** Проверьте Wi-Fi, VPN на телефоне, гостевую сеть/изоляцию клиентов, разрешения приложения на доступ к локальной сети. TV должен быть запущен.

**Пульт подключается, но кнопки молчат, либо закрывается при нажатии.** Выполните восстановление комплекта при закрытом Android, затем откройте TV и заново экран пульта. Это исправляет отсутствие `/dev/uinput` и Android event node; очищать данные Remote Service не нужно.

**Пульт перелетает пункты.** Проверьте наличие `/etc/udev/rules.d/72-waydroid-atv16-remote.rules`, затем закройте и снова откройте пульт. Новое устройство должно быть изолировано от Steam/gamescope.

**Чёрный экран/сбой видео.** Начните с журнала запуска. Автор образа рекомендует при видеопроблемах проверить отключение аппаратного ускорения видео или zero-copy в «Настройки → Система → Waydroid options»; это не универсальное решение для всех чёрных экранов. [Примечания релиза](https://github.com/WayDroid-ATV/waydroid-androidtv-builds/releases/tag/20260403).

## Данные и резервная копия

Остановите TV и сохраняйте **оба каталога вместе**:

- `/home/deck/Android_Waydroid_ATV16/var-lib-waydroid` — образы, конфигурация и overlays.
- `/home/deck/.local/share/waydroid-atv16` — приложения, аккаунты, настройки и сопряжение.

При восстановлении Android необходимо сохранить числовые UID/GID и права файлов: простое копирование через FAT/exFAT для этого не подходит. Системную интеграцию можно восстановить командой `bash install.sh --repair`.

Комплект намеренно не содержит команды автоматического factory reset или удаления пользовательских данных. Обновление образов на другой релиз также не автоматизировано: bpfloader-исправление привязано к проверенному релизу.

## Структура проекта

```text
install.sh / start.sh / add-to-steam.sh / doctor.sh
scripts/    установка основы и TV, сборка переносимого архива
runtime/    проверенные рабочие launcher, root helper, пульт и правила
docs/       архитектура, проверки и происхождение кода
tests/      автоматические проверки комплекта
dist/       готовый ZIP для переноса на чистый Deck
archive/    старые одноразовые команды и диагностические материалы
local/      личные инструменты SSH и known_hosts; не включаются в ZIP
```

В установочном архиве нет пароля, адреса вашего Deck, SSH-ключей, личных файлов, Android-образов и архивных диагностик. Для передачи другому человеку используйте ZIP из `dist`, а не всю рабочую папку.
